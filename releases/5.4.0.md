# Eclipse Arrowhead 5.4.0 — release notes (in development)

**Status:** Not released. `main` carries 5.4.0 development.
**Comparison baseline:** [5.3.0](5.3.0.md), tag `v5.3.0`.

## Changes since 5.3.0

- Build and reported framework/system versions are 5.4.0.
- Release notes are under `releases/`; the documentation overview is `documentation/Documentation.md`.
- New (Java only): WorkflowManager (8482) and WorkflowExecutor (8483) in `ah5-Workflow-java/`, coexisting with the
  Choreographer (architecture option A). Execution semantics follow Varga, Sensors 2026, 26, 7025. Go and Rust
  implementations do not exist yet, so these systems are not interoperable across the three implementations.
  Verified on 2026-11-20 in the running Java test cloud with the secure profile (`ah5-Workflow-java/verification/cloud/`,
  34/34 checks), including the cloud's Choreographer running a compiled recipe on a WorkflowExecutor. The test found a ServiceRegistry defect, not fixed: concurrent first registrations of a new service
  definition fail with HTTP 500 (duplicate key).
- New (Java only): WorkflowConfigurator (8484, browser console 8485) in `ah5-Workflow-java/`: a graphical editor that
  lists the configured local clouds (running cloud, LocalCloudConfigurator designs, SoLC member clouds) and their
  services, draws workflows as state machines or sequence diagrams with conditions, and stores them in the
  WorkflowManager. The recipe format gains guarded transitions (`guards`, extension x-guard; skipped steps x-skip).
  Verified on 2026-11-21 in the Java test cloud (49/49 checks) and in a browser. Not interoperable with Go or Rust
  (they have no workflow systems).

Qualification evidence will be recorded in [verification/release-5.4.0](../verification/release-5.4.0/README.md).
